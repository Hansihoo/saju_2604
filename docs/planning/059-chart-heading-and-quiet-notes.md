# 059 · 사주팔자와 읽는 법, 조용한 풀이 메모

2026-10-10 직접 사용자 피드백: 사용자는 사주를 읽으려 하며 사이트 설명서를 읽으려 하지 않는다. 상단은 **내 사주팔자 → 네 기둥과 언어별 읽는 법**으로 보여준다. 반복되는 날짜 관례/가정/보류/범위 안내는 본문에서 빼고 기본 접힘 풀이 메모에 보존한다.

## 범위와 경계

- KO 제목 `내 사주팔자`, EN 제목 `My birth chart`. 기존 으쓱 캐릭터는 유지한다. 소개 문장은 제거한다.
- 한자 아래 KO 독음/EN 한국어 로마자 독음을 표시한다. 현재 지원 언어 ko/en과 기존 `formatManseText` 표를 재사용한다. 한국어 기둥명을 영어 한자음으로 바꾸지 않는다.
- 주 결과의 계산 안내/분류별 publication notice/하단 범위 안내는 첫 장 또는 해당 장의 풀이 메모 안으로 이동한다. 질문 답변과 호환 기본 풀이도 같은 접힘 표시를 따른다.
- 본문이 말하는 유불리의 실제 조건은 지우지 않는다. 안내 데이터, 대안 명식, critical 전체 보고서 보류, 미상 시주, 질문 허용 범위와 공유 카드 한계는 유지한다. 새 판정이나 모델 호출을 만들지 않는다.
- 과거 문서의 ‘불확실성 안내를 본문 밖에 항상 표시’는 이번 명시적 사용자 요청으로 표시 위치만 대체한다. 자료와 판단의 경계는 유지한다.

## 위험과 검증

안내 누락, 번역 혼합, 미상 시주의 가짜 독음, 좁은 화면의 줄 넘침을 확인한다. TypeScript/웹 빌드, 기존 웹 helper, fallback-only 사용자 시나리오와 실제 브라우저 KO/EN 표시·메모 열기/닫기를 검증한다. 새 판정·정확도·흥미 검증으로 보고하지 않는다. 기존 음력30일 검증 실패와 콘텐츠 효용 미승인 상태는 보존한다.

표시 정책은 `chart_header_presentation-2026-10-10.1`로 독립 관리한다. 연관 작성 계약 whole_chart_reading.3/distinctive.7은 같은 표시 정책을 참조한다. 계산·지식·해석·모델 버전은 변경하지 않는다.
