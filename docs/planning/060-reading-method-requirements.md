# 사주풀이 작성 기준 통합

2026-10-10. 작성 기준 버전 reading-method-review-2026-10-10.2. 기존24개 요구를 여섯 역할로 통합했다. 새 종합 판정기와 작성 경로는 후속 구현 대상이다.

독자는 본문에서 자기 사주의 중요한 특징과 유리함·불리함, 지원되는 시기 변화를 이해한다. 왜 그렇게 풀이했는지는 기본 접힘 근거에서 확인한다. 각 역할의 요구는 한 곳에만 정의하며, 같은 결론을 여러 규칙에 맞춰 반복 작성하지 않는다.

직접 사용자 피드백: “서로 겹치는 내용이라서 문제가 되는 것 같아. 너가 보고 정리해줘”. 앞선 “즉 전문용어 나오는 곳과 풀이하는곳을 분리해”, “이 사주는 하나의 예시의 뿐이야 근본적인 문제를 찾아”라는 요구도 유지한다.

| 기준 | 담당하는 일 | 산출물 |
| --- | --- | --- |
| C01 판단 | 전체 조건과 반대 단서를 검토해 말할 수 있는 결론을 정한다. | 근거와 범위가 있는 개인별 결론 |
| C02 분야별 내용 | 결론을 관심 분야와 기간에 배치한다. | 중복되지 않는 다섯 분야의 내용 |
| C03 본문 | 선택된 결론을 이해 가능한 풀이로 쓴다. | 항상 보이는 완결된 풀이문 |
| C04 근거 | 같은 결론이 나온 전문적 이유를 설명한다. | 눌렀을 때 펼쳐지는 상세 근거 |
| C05 추가 질문 | 본문 다음에 더 알아볼 질문을 고른다. | 실제 답변 가능한 개인별 후속 질문 |

여섯 기준마다 본문 문단을 만들지 않는다. 분야와 분석 재료의 목록도 모두 채워야 하는 문단 수가 아니다.

## C01 판단

계산된 전체 명식에서 주요 결론과 유리함·불리함, 작용 정도와 조건을 함께 판단한다. 한 항목의 정의나 존재를 곧바로 개인의 운세로 확대하지 않는다. 함께 있다는 사실과 서로 돕거나 막는 작용을 구별한다. 상쇄·강화·완화는 적용 가능한 규칙이 있을 때 판단한다.

검토할 재료는 세 범위로 묶는다.

- 기반: 일간·계절·월령, 겉글자·지장간, 뿌리와 도움, 기운을 쓰거나 제약하는 관계.
- 구조: 강약·격국·특수 구조, 생극·합충·제화, 조후·억부·통관 등 용신 관점의 차이, 성립 조건과 예외.
- 분야와 기간: 돈·일·인연의 판단 규칙, 원국과 대운·세운·월운의 관계, 같은 사람의 기간 비교와 반대 단서.

결론에는 실제 사실·규칙/출처·조건·범위가 연결되어야 한다. 계산 사실, 전통 정의, 개인별 판단과 예시/조언을 구별한다. 겉글자/신살 개수와 내부 점수를 강약·능력·확률·인구 순위·사건 날짜로 바꾸지 않는다. 부족한 오행을 자동 용신으로 정하거나 신약을 정신력·건강의 약함으로 쓰지 않는다.

시간 미상·자료 누락·날짜 관례 차이의 기존 제한과 critical 전체 보류를 유지한다. 대안 명식은 독립 재파생한다. 모든 명식에 같은 판단 체계를 적용하고 예시 생일 분기를 만들지 않는다. 전체 강약/격국/용신, 분야별 종합과 사건 시기 판정, 전문가/실증 승인은 현재 미완료다. 이 기준은 그 공백을 문장으로 채울 권한이 아니다.

## C02 분야별 내용

C01에서 지원된 결론만 다음 분야에 배치한다. 전체 의미는 특징 장에서, 특정 분야의 추가 의미는 해당 장에서 설명한다. 새 정보가 없으면 같은 설명을 다른 말로 반복하지 않는다.

| 분야 | 독자가 얻을 내용 |
| --- | --- |
| 내 사주의 특징 | 전체 기조와 가장 중요한 복·부담 |
| 연애·결혼 | 인연과 관계의 유리함·불리함 및 지원되는 변화 |
| 금전 | 벌이·보상, 모이는 조건, 지출·손실 부담의 구별 |
| 직장·직업 | 일자리·기회, 책임·평가, 인정·보상의 구별 |
| 현재와 다음 운 | 타고난 조건을 돕거나 부담을 더하는 기간별 차이 |

앞으로의 인연·취업·직장 변화와 시기가 주력 관심사다. 성격·학습/업무 스타일을 직접 답으로 대신하지 않는다. 10년 대운의 이름이나 기간만 설명한 것을 사건 시기 답으로 취급하지 않는다. 답변 가능 여부는 C01에서 정한다.

## C03 본문

질문을 누르지 않아도 내 사주에 대한 풀이가 완결되어야 한다. 중요한 결론부터 말하고, 그것이 사용자에게 어떤 뜻인지와 결론을 바꾸는 실제 조건을 자연스럽게 연결한다. 새 판단을 만들거나 전문 분류를 추상적 대체어로 옮겨놓지 않는다. 문장의 대상과 뜻을 명확히 하며 “몫·흐름·밑바탕” 같은 말의 의미를 독자가 추측하게 하지 않는다.

친근하고 솔직한 반말로 필요한 만큼 설명한다. 불리함을 장점·성장 기회로 자동 미화하지 않는다. 비유는 뜻을 밝힐 때 짧게 사용하고 조롱·공포·가짜 개인사를 만들지 않는다. 고정 문장/문단 수, 장점과 단점의 같은 개수, 생활 장면·조언·숙제의 강제는 두지 않는다. C01의 판단 범위 안에서 명확하게 말한다. 전문 자료의 표시 위치는 C04가 정한다.

## C04 근거

전문용어와 한자, 실제 명식과 위치, 적용 규칙·출처, 판단 과정, 반대 단서·대안·정밀 계산 자료는 기본 접힘 영역에 두고 눌렀을 때 자세히 보여준다. 본문과 같은 결론에 대해 어떤 사실과 규칙을 적용하고 다른 조건을 고려해 왜 그 결론을 선택했는지 설명한다. 용어 사전이나 본문을 어렵게 반복한 글로 끝내지 않는다.

본문에는 결론의 생활상 의미와 실제 성립 조건을 남긴다. 반복된 계산 관례·가정·보류·서비스 범위 안내의 위치는059 정책을 따르며 원본 안내와 지원 제한 자체는 보존한다. 근거를 펼치지 않아도 본문은 이해할 수 있어야 한다.

## C05 추가 질문

본문 다음의 궁금증 중 실제 답변할 수 있는 질문을 고른다. 태극·도화 등의 이름은 실제 확인된 특징의 개인별 의미를 묻는 질문에 사용할 수 있다. 본문에 신살별 소개를 강제하거나 보조 표시로 전체 풀이를 대신하지 않는다. 없는 특징과 미지원 질문은 흥미 장치로 공개하지 않는다.

질문에 필요한 상황만 받는다. 새 인연/교제 중, 구직/재직을 구별하고 미응답은 추측하지 않는다. 본인 사주로 상대 속마음이나 관계 결과를 확정하지 않는다. 질문마다 원하는 정보에 직접 답하며 같은 답의 제목만 바꾸지 않는다. 캐릭터·공유·재방문은 실제 새로운 정보와 다음 질문을 보조한다.

## C06 검증

실제로 보이는 본문과 펼친 근거를 확인한다. 계산/규칙 일치, 문장 이해도와 문단 연결, 질문 충족과 개인별 효용, 실사용 만족을 구별한다. 분류·개수·방법 설명을 빼고도 풀이 결론이 남는지, 반대 조건의 다른 명식에서 결과가 적절히 달라지는지 검사한다.

본문·근거·질문 답·요약·공유·다국어는 같은 사실과 판단 범위를 유지해야 한다. 공유 시 조건을 지워 강한 예언으로 바꾸거나 출생정보를 기본 포함하지 않는다. 일반·시간 미상·날짜 경계와 여러 상반 조건을 검토한다. 기술PASS만으로 콘텐츠 실패·전문가 미검토·실사용 미검증을 해제하지 않는다. 역할 prompt/rubric과 의미 검증 자동화 반영은 후속 구현 대상이다.

## 겹치거나 충돌한 지시의 처리

| 기존에 섞인 지시 | 적용 위치 |
| --- | --- |
| 전체 기조·종합·좋고 나쁨·반대 조건을 각각 본문으로 요구 | C01에서 함께 판단하고 C03에서 필요한 설명만 쓴다. |
| 결론부터·충분한 본문·쉬운 말·분량을 각각 출력 형식으로 요구 | C03으로 통합한다. 길이와 문단 수를 목표로 두지 않는다. |
| 본문에서 왜 그런지 설명·전문 근거는 접기 | C03은 결론의 의미, C04는 전문적 판단 이유를 담당한다. |
| 미래 시기가 주력 관심·현재 시기 규칙은 미지원 | 관심 분야는 C02, 답변 가능 여부는 C01이 정한다. |
| 장점/단점 모두 제시·억지 균형 금지 | C01에서 성립한 판단만 쓰고 양쪽 개수를 채우지 않는다. |
| 유명 특징 알리기·태극은 질문 장치 | C05가 개인별 발견 질문을 담당하고 본문 소개는 강제하지 않는다. |

이 표는 적용 위치를 설명하며 추가 문단 목록이 아니다. 과거025의 점수/단순 개수/능력 예시, 026의 최소 길이·소제목·bullet 강제, 이후 대체된 근거 항상 표시와 신살 소개 강제는 현재 기준으로 재사용하지 않는다.

## 구현 상태와 근본 문제

2026-10-10 [063 반영](063-reading-conclusions-and-followup-coverage.md)은 분석 블록과 게시 결론을 분리하고 기존 월/지원 판단을 조건·근거와 함께 연결한다. 질문의 쉬운 설명은 기본 본문으로, 전문 자료는 접힌 메모로 표시한다. 다음 질문은 실제 답의 의미 범위를 사용해 서버에서 고르며 UI와 캡처가 같은 메뉴를 사용한다. 아래의 직접 블록 게시 진단은063 이전 경로를 설명한다. 제한된 결론 연결은 전체 명식·분야·기간의 종합 판정기를 대신하지 않으며, 그 공백과 콘텐츠 검증은 별도로 남는다.

2026-10-10 후속 [061 런타임 검증 스킬](061-runtime-content-verification-skill.md)은 C06을 실행하는 별도 workflow와 평가 rubric을 추가한다. 쉬운 문구·궁금증 충족·후속 흥미/실제 답을 독립 검토하며 C01~C05의 작성 기준을 다시 정의하지 않는다. 아래 종합 판단/작성 경로의 공백은 이 검증기 추가로 해소되지 않는다.

현재 `natal_structure.render_structure`는 개별 조건별 고정 문단을 선택하고 `reading_publication.publish_chapter`는 이를 직접 게시한다. 이 경로의 종합 판단과 결론 연결 공백은 규칙 수를 줄이는 것만으로 해결되지 않는다. 후속 구현에서는 C01의 판단 결과를 C02~C05에서 각각 사용하고 C06으로 실제 의미를 확인하는 방법을 검토한다.

이번에는 작성 요구를 통합했으며 계산/판정기·문구·프롬프트·UI·역할rubric·provider는 변경하지 않았다. 058의 기술검증은 보존하지만 사용자가 거절한 본문 이해도와 종합 풀이 만족은 여전히 Needs review다.
