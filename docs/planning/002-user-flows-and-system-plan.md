# User Flows And System Plan 002

## 목적
- 문제 정의를 바탕으로 대표 사용자 흐름, 시스템 책임 분리, 입력 정책 후보를 정리한다.
- 다음 회차에서 화면 구조와 UX를 설계할 수 있도록 사용 시나리오 중심의 틀을 만든다.

## 대표 사용자 후보
- 사주를 처음 접하지만 자신의 성향과 운 흐름을 쉽게 보고 싶은 일반 사용자
- 기존 사주 콘텐츠는 많이 봤지만, 더 논리적이고 근거 있는 해석을 원하는 사용자
- 궁합이나 고급 분석 전, 먼저 개인 기본 해석을 확인하고 싶은 사용자

## 핵심 사용자 가설
- 첫 MVP의 중심 사용자는 "사주를 잘 모르지만 자기 해석을 쉽게 보고 싶은 모바일 사용자"로 둔다.
- 이유:
  - 단계적 공개 UX와 설명형 해석 구조가 이 사용자군에 가장 잘 맞는다.
  - 고급 분석 전에도 기본 입력과 결과만으로 명확한 가치 전달이 가능하다.

## 대표 정상 흐름
1. 사용자가 서비스 소개를 보고 개인 해석 시작을 선택한다.
2. 양력/음력 기준, 생년월일, 생시(HH:mm), 성별, 지역을 입력한다.
3. 사용자가 지역 입력창에 텍스트를 입력하면 시스템이 연관 지역 후보를 제안하고, 사용자가 그중 하나를 선택한다.
4. 시스템이 선택된 지역과 시간 정보를 기준으로 시간 보정을 수행한다.
5. 출생시간이 기본값 `00:00`인지 확인하고, 시주 기반 계산/표현 제한 여부를 함께 결정한다.
6. 사주팔자와 만세력 데이터를 계산한다.
7. 분석 엔진이 점수와 등급을 산정한다.
8. LLM이 계산 결과를 설명형 결과로 구성한다.
9. 사용자는 요약 결과를 먼저 확인하고, 상세 설명과 근거를 단계적으로 펼쳐본다.

## 대표 실패 흐름
- 지역 정보가 모호해서 타임존을 확정할 수 없는 경우
- 해당 지역/시점의 역사적 시간 보정 데이터를 처리하지 못한 경우
- 생시를 모르는 사용자가 기본값 `00:00`으로 진행했지만 시주 기반 결과를 일반 결과처럼 오해하는 경우
- 계산 엔진 결과는 나왔지만 LLM 표현이 정책을 벗어나는 경우

## 실패 시 제품 원칙
- 계산이 불가능하면 억지 결과를 보여주지 않는다.
- 신뢰도가 낮아지면 그 이유를 사용자에게 명확히 알린다.
- LLM 출력은 내부 정책 검사를 거친 뒤 반환한다.
- 특별 등급은 조건 미충족 시 부여하지 않는다.
- 출생시간 미상일 때는 시주 의존 정보와 그 기반 해석을 비활성화하거나 제한 표시한다.

## 시스템 책임 분리
- Frontend:
  - 입력 수집
  - 단계적 결과 표시
  - 근거/설명 펼침 UI
- API Server:
  - 입력 검증
  - 요청 오케스트레이션
  - 결과 조합 및 응답
- 시간 보정 모듈:
  - IANA 타임존 확인
  - 역사적 시간 변경 반영
  - DST 반영
- 사주 계산 모듈:
  - 시간 보정 후 사주팔자 계산
- 만세력 생성 모듈:
  - 천간/지지
  - 십성
  - 오행 분포
  - 대운
- 분석 엔진:
  - 등급 산정
  - 점수 산정
  - 해석 근거 정리
- LLM 레이어:
  - 결과 요약
  - 상세 설명
  - 사용자 친화적 문장화

## MVP 시스템 경계
- MVP 포함:
  - 단일 사용자 개인 해석
  - 입력 검증
  - 시간 보정
  - 사주/만세력 계산
  - 점수/등급 산정
  - 기본 해석 반환
- MVP 제외:
  - 궁합
  - 멀티 프로필 비교
  - 고급 리포트 결제
  - 운영자 도구
  - 결과 저장

## 이번 회차 결정
- 첫 MVP는 개인 해석 단일 흐름에 집중한다.
- 제품 신뢰를 위해 실패 흐름도 초기부터 설계 범위에 포함한다.
- 결과 데이터는 계산 데이터, 판단 데이터, 표현 데이터를 분리해서 다룬다.
- 생시는 분 단위까지 받으며 입력 누락 시 계산을 진행하지 않는다.
- 출생시간 미상 사용자는 기본값 `00:00`으로 진행 가능하게 하되, 시주 의존 결과를 비활성화한다.
- 첫 지역 경험은 한국 중심으로 설계한다.
- 결과는 내부 점수/등급을 유지하되 사용자에게는 요약형 표현을 우선 제공한다.
- 지역 입력은 검색형 제안 리스트에서 사용자가 선택하는 방식으로 설계한다.
- 오행, 십성, 대운은 기본 접힘 상태로 제공하고 사용자가 원할 때 펼쳐본다.
