# 055. 확인된 특징과 의미 질문 연결

2026-10-09. 제한된 보조 주제/질문 구현·동작 검증 완료. 전체 콘텐츠 효용은 보강 중.

## 목표와 범위

사주를 모르는 독자가 본문에서 유리한 뜻과 부담을 먼저 얻고, 실제 발견된 특징의 의미를 더 묻는다. 생년월일별 예외나 신살 목록 채우기가 아니라 backend의 검증된 계산 사실과 명시된 관법 조건으로 선택한다. 계산 정책033과 기존 critical 전체 보고서 보류는 유지한다.

전체 원국 강약·큰 길흉·만남/취업 시기 판정까지 지원한 것으로 과장하는 것이 주요 위험이다. 이번 구현은 두 개의 **제한된 전통 보조 주제**이며 원국 종합 완성은 아니다. 출현·개수로 강도·확률·순위를 만들지 않는다. 전문가 타당성과 실사용자 흥미는 별도 미검증이다.

## 구현 계약

- `distinctive_reading`과 독립 knowledge/rules/copy 버전 카탈로그. 원본 facts와 실제 적용 `eligible_matches`를 분리한다. frontend는 supplied publication만 렌더링한다.
- 문창의 현행 庚→亥 관법과 일지 화개가 각각 유효하고 적용 위치에 공망/충이 없을 때 배움·글의 좋은 뜻과 고독·거리의 부담을 함께 설명한다. 상호 강화/취소나 재능·합격·직업 성공은 판정하지 않는다. 화개 관법도 명시적으로 제한한다.
- 왕지도화와 일지에 걸친 원진의 현행 common-KR 관법이 각각 유효할 때 관심/호감과 가까운 관계의 엇갈림을 구별한다. 고전 함지/원진(元辰)과 동일시하지 않는다. 특정 관계 상태를 추측하지 않는다.
- 태극귀인은 실제 유효 match와 관련 배움/고독 주제가 있을 때만 별도 의미 질문을 공개한다. 도화와 배움/고독도 각 전용 답변을 제공한다. 기존 위치 질문의 제목만 바꾸지 않는다.
- 검증된 자정 관례 차이만 조건부로 읽고, 실제 primary policy 가정을 본문과 질문 답변 밖에 표시한다. 다른 명식을 재계산한 주제/원본 파생 사실은 기본 접힘 메모에 둔다. 추가 critical/시간 미상/불일치 사실은 공개하지 않는다.
- 기술 자료와 출처는 기존 question sections의 접힌 메모에 보존한다. 짧은 `ReadingBasisExplanation`에 긴 자료를 억지로 넣지 않는다.
- 주제 없는 critical 분야의 빈 장은 숨기고, 발견 신살의 사전식 자동 나열은 중단한다. 전체 보고서 보류는 해제하지 않는다.

## 출처와 한계

카탈로그에 원문 링크·관법·적용 범위를 기록했다. 文昌 표는 [命理探源](https://shuyuan.zhiming.life/read/命理探源/8)의 庚→亥이며 다른 판본의 庚→寅 표와 섞지 않는다. 화개의 학예/고독은 [三命通會 論將星華蓋](https://www.shidianguji.com/zh/book/SK1610/chapter/1m8rrfw2pczlr), 태극의 始終相保는 [三命通會 卷三](https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/卷03)에 대응한다. 추가 성립 조건을 검증하지 않고 큰 복/구원자/평생 성공으로 바꾸지 않는다. 겨울 경금의 조후나 식신생재는 이번 규칙으로 구현하지 않았다.

## 검증

실제 API 응답·질문 답변, 조건 제거/관법 오류/중복/공망/추가 critical/다른 명식 재계산/원본 fact 대응을 테스트한다. 전체 API, 웹 타입/빌드/기존 helper, fallback-only 사용자 흐름, 실제 개인 결과와 메모/질문/복귀를 확인한다. 질문자·답변자·감독관은 새 실제 snapshot을 독립 검토하고 과거053 효용 FAIL을 덮어쓰지 않는다. 유료provider는 검증에 호출하지 않는다.

독립 r2 세 역할 및 합계는 **FAIL**이다. 질문자는 개인 본문의 제한된 유불리 설명과 배움/도화 질문 효용은 PASS, 태극 질문은 추상성 때문에 HOLD, 일반KO/EN·시간 미상 본문은 FAIL로 평가했다. 읽기 쉬움은7사례 모두 PASS지만 실사용자 흥미나 예측 정확도 인증은 아니다. 답변자는347 frozen facts의 정확한 원본 대응을 확인하고 일반 본문 부족·태극의 구체 효용을 미완료로 남겼다. 감독관은 대안 속성 혼입 해소와 개인 질문의 좁은 직접답을 인정하되 비교 범위/강도 표제/실제 부담처럼 읽히는 표현을 지적했다. 잘못된 review 파일명으로 첫 aggregate가 HOLD였던 기록도 보존했고 올바른 파일명으로 합계 FAIL을 확인했다.

후속 copy.2는 사실·규칙 버전을 유지하고 문구만 독립 변경했다. 태극 질문은 **“태극귀인이 있으면, 누군가 도와준다는 뜻일까?”**로 실제 답할 수 있는 약속으로 좁히고 배움·글의 복은 다른 표시에서 읽는 뜻임을 분리했다. 질문자는 이 제안의 질문 적합성을 별도로 인정했다. 고독/관계 부담은 실제 상황 단정이 아니라 표시의 아쉬운 뜻으로 정리했고, 접힌 세부 제목은 지원하지 않는 강도 대신 읽을 수 있는 범위를 묻는다. 비교는 선택한 조합에 한정하며 개별 표시의 소멸을 뜻하지 않는다고 명시한다. 태극은 대안의 연주에 남는 실제 위치도 표시한다. 질문별 메모 비교도 해당 조합으로 한정했다. 독립 copy `distinctive-copy-2026-10-09.2`, question copy.4/category copy.8, publication.4다.

최신 실제 개인 본문+질문3의4사례는 r3로 별도 동결했다. 적용하지 않은 legacy facts/정책을 제외하여 제한된 보조 풀이를 검토하는 범위를 줄였으며 원본 전체 snapshot은 따로 보존한다. r2의 일반/미상 FAIL을 이 검토로 해제하지 않는다. 원국 전체의 큰 복/불운·돈/직장·만남 시기 규칙과 전문가 검증은 계속 미완료다.

r3 개인4사례의 질문자·감독관은 제한된 뜻과 질문 직접답을 **PASS**, 답변자와 합계는 **FAIL**로 평가했다. 답변자도23개 facts의 원본 대응과 문구 범위/직접답은 PASS였다. 남은 지적은 기술 표시·위치를 본문에도 쓰는 것과 전체 분야 보류 상태를 사용자에게 명시하는 것이다. 전자는 전문용어/근거를 접힌 메모에 숨겨달라는 사용자의 명시 요구를 유지하여 적용하지 않았다. 이것을 검토 PASS로 바꿔 보고하지 않는다.

후자는 category copy `.9`로 교정했다. 기존 명식 가정과 별도로 **“날짜 기준에 따라 명식이 달라져 종합 풀이는 보류했어. 아래는 확인된 특징만 조건부로 읽은 내용이야.”**를 접히지 않는 계산 안내에 표시한다. 특징 knowledge/rules/copy와 질문 copy는 그대로다. 최종 category7 검사, 새로운 fallback ASGI4/167 checks, 실제 reading/질문3 모두 통과했고 r4 새 snapshot을 생성했다. 첫 category7 재실행은 격리 fallback 환경 누락으로 정상 입력2건이 provider guard409를 반환했으며 환경을 바로잡아7통과했다. 실패와 통과를 함께 보존했다. 이 마지막 안내 변경은 독립 역할 재승인으로 포장하지 않으며 r3 aggregate FAIL과 r2 일반/미상 FAIL은 유지한다.
