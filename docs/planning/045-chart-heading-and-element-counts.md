# 사주팔자 제목과 오행 개수 표시

후속 사용자 요청에 따라 [046](046-plain-reading-and-folded-evidence.md)에서 오행 개수·일간 설명을 기본 접힘 `풀이 메모`로 옮겼다. 상단 사주팔자·으쓱 캐릭터와 단순 집계/해석 구별은 유지한다. 이 문서의 상시 집계 표시는 최신 UI 계약이 아니다.

2026-10-08 사용자 요청: 맨 위에 사주팔자를 표시하고, 옆에는 으쓱하는 도깨비를 둔다. 오행은 해석 기준에 따라 달라지는 것 아니냐는 질문도 함께 검토했다.

## 목표와 범위

기본 결과의 제목·캐릭터·오행 표시를 보정한다. 단순 개수를 기운의 강약으로 오해하지 않게 하며, 동일 캐릭터의 새 표정을 재사용할 수 있게 한다. 계산 정책 033, backend 판단, 모델/provider, 질문별 지원 범위는 변경하지 않는다. 위험은 개수 0을 전체 기운의 부재로 읽거나, 새 표정을 분석 정확도의 표시로 사용하는 것이다.

## 실제 계산 기준

`analyze_saju.py`의 `_count_visible_elements`는 표시되는 각 기둥의 천간과 지지 대표 오행을 각각 한 번 센다. 지장간·월령·조후·합에 대한 가중치는 포함하지 않는다. 생시가 알려지면 8글자, 생시 미상이면 6글자다. 같은 명식과 같은 집계 기준이면 개수는 같지만, 출생 시각 보정과 날짜 경계 정책에 따라 명식 자체는 달라질 수 있다.

사용자 사례 `戊辰 癸亥 庚辰 丙子`의 겉글자는 목 0·화 1·토 3·금 1·수 3이다. 辰의 乙과 亥의 甲은 지장간에 있어, 목 0을 사주 전체에 목이 없다는 뜻으로 설명하면 안 된다. 기운의 강약은 이 숫자만으로 결정하지 않는다.

## 다른 서비스의 공개 설명

- [사주길 공식 공개 샘플](https://sajugil.com/sample)은 가중치를 반영한 오행 비율을 표시하고, 같은 명식의 신강·신약에 대해 부조 비율과 득령·득지·득세 기준의 결과를 함께 제시한다. 관법 차이를 설명한 공개 예시이며 가중치 전체 공식이나 과학적 정확도를 확인한 것은 아니다.

두 사례는 집계와 해석 기준을 명시하는 방향을 뒷받침한다. 경쟁 서비스의 수치를 그대로 복제하거나 한 방식만 정답으로 취급하지 않는다.

## 구현

- 제목은 `사주팔자`, 보조 문장은 `사주에 있는 그대로 말해줄게.`다.
- 기본 명식 제목 옆만 `shrug`를 사용한다. 사용자의 갤러리 선택은 다른 화면·질문 답변·공유에 유지된다.
- 내장 image_gen으로 기존 `smirk.png`를 참조해 두 손을 든 같은 도깨비를 생성했다. 새 `shrug.png`·catalog·manifest·ZIP을 함께 관리한다. 실제 프롬프트는 manifest의 shrug 항목에 저장했다.
- 오행 제목은 `겉글자 기준 · 오행 개수`, 한국어 숫자는 `개` 단위를 붙인다. 작은 설명은 `지장간은 빼고 센 개수야. 기운의 강약은 이 숫자만으로 정하지 않아.`다. 영어에도 같은 범위를 설명한다.
- 제품 지식의 독립 `chart_presentation.version`을 추가한다. 사실·해석·본문 문장 버전은 유지한다.
- 320px 브라우저에서 세로 스크롤바가 차지하는 폭 때문에 기존 `body`의 고정 최소 320px가 가로 스크롤을 만들었다. 최소 너비를 `min(320px, 100%)`로 바꿔 실제 사용 가능한 폭을 넘기지 않도록 한다. 검증은 `innerWidth`뿐 아니라 문서 `clientWidth`와 `scrollWidth`도 비교한다.

향후 가중치 해석은 근거 문헌·규칙·예외·검토 상태·버전을 갖춘 별도 결과로 설계해야 한다. 원시 개수를 가중치 결과로 덮어쓰거나 이를 사건 확률·순위·유리한 날짜로 변환하지 않는다.

## 검증

2026-10-08 완료:

- 최종 웹 타입/빌드, 웹 helper 14건·진행 계약 7건, 기본 본문 API 14건 통과. 표시 변경 범위이며 전체 API 회귀를 다시 실행한 것은 아니다.
