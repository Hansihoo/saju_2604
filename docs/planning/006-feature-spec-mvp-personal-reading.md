# Feature Spec 006 - MVP Personal Reading

## 1. 기능명
- `MVP 개인 사주 해석 조회`

## 2. 목적
- 사용자가 자신의 기본 사주 해석을 신뢰감 있게 조회할 수 있도록 한다.
- 정확한 계산과 설명 가능한 해석을 한 번의 흐름으로 연결한다.

## 3. 대상 사용자
- 주요 사용자:
  - 사주를 잘 모르지만 자신의 해석을 쉽게 보고 싶은 일반 사용자
- 사용자 가치:
  - 어려운 용어를 몰라도 요약된 해석을 빠르게 이해할 수 있다.
  - 필요하면 오행, 십성, 대운 근거까지 펼쳐볼 수 있다.

## 4. 사용자 시나리오
- 정상 흐름:
  - 사용자가 양력/음력, 생년월일, 생시, 성별, 지역을 입력한다.
  - 지역 자동완성에서 후보를 선택한다.
  - 시스템이 시간 보정 후 계산/분석/해석을 수행한다.
  - 사용자는 요약 결과를 먼저 보고 필요하면 근거를 펼친다.
- 대체 흐름:
  - 사용자가 출생시간을 모르면 `00:00`으로 진행한다.
  - 결과에서는 시주 기반 정보가 제한된다.

## 5. 화면 범위
- 포함 화면:
  - 입력 화면
  - 결과 화면
  - 오류/제한 안내 UI
- 포함 컴포넌트:
  - 양력/음력 토글
  - 날짜/시간 입력
  - 성별 선택
  - 지역 자동완성 입력
  - 요약 결과 카드
  - 상세 근거 아코디언
- 화면 간 이동:
  - 입력 -> 결과
  - 오류 발생 시 입력 화면 내 수정 유도

## 6. 데이터/API 범위
- 필요한 입력:
  - `calendar_type`
  - `birth_date`
  - `birth_time`
  - `is_birth_time_estimated`
  - `gender`
  - `region selection`
- 필요한 출력:
  - 요약 결과
  - 강점/약점
  - 연애운/직업운/금전운
  - 대운 흐름
  - 행동 조언
  - 상세 근거
  - 시주 제한 정보
- 연동 API:
  - 지역 검색 API
  - 개인 해석 생성 API
- 저장/조회 데이터:
  - MVP에서는 결과 저장 없음

## 7. 예외/실패 흐름
- 실패 케이스:
  - 지역 선택 누락
  - 시간 보정 실패
  - 양력/음력 변환 실패
  - 계산 엔진 실패
  - LLM 출력 스키마 실패
- 사용자에게 보여줄 피드백:
  - 어떤 입력을 다시 확인해야 하는지 명시
  - 계산 불가 시 결과 대신 안내 메시지 노출
  - 출생시간 미상 시 제한 안내 노출
- 로그로 확인할 포인트:
  - 지역 매핑 실패
  - 시간 보정 예외
  - 계산 엔진 예외
  - LLM 응답 파싱 실패

## 8. 비범위
- 로그인
- 결과 저장
- 궁합
- 결제
- 관리자 도구
- 해외 지역과 다국어 UI

## 9. Acceptance Criteria
- [ ] 사용자는 양력/음력 기준을 선택할 수 있다.
- [ ] 사용자는 지역 검색 후 제안 리스트에서 하나를 선택해야 제출할 수 있다.
- [ ] 출생시간 미상 시 `00:00`으로 진행 가능하고 제한 안내가 노출된다.
- [ ] 시스템은 시간 보정 후 계산 엔진을 호출한다.
- [ ] 결과 화면은 요약형 해석을 먼저 보여준다.
- [ ] 오행, 십성, 대운 근거는 접힌 상태로 제공된다.
- [ ] 계산 불가 또는 보정 실패 시 잘못된 결과 대신 오류 안내가 나온다.
