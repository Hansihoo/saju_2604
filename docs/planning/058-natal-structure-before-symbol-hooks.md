# 058. 명식 구조를 먼저 읽고 보조 표시는 질문으로

2026-10-10. 작업 유형: 서버 풀이/표시 계약 보강. 057의 실제 구현 단계.

## 목표와 경계

본문은 월의 중심 관계, 같은 기운의 뿌리와 도움, 겉/안쪽의 재물 표시, 결과와 책임의 공존을 연결해서 설명한다. 태극귀인은 본문에 억지로 삽입하지 않고 실제 검출된 개인 질문에서 존재와 의미를 연결한다. 전문 용어·원본·반대 단서는 기본 접힘 풀이 메모에 둔다.

영향 범위는 새 독립 natal 구조 모듈/카탈로그, category publication, 추가 응답 필드와 검증이다. 기존 계산033/LLM/legacy report는 유지한다. 신강·신약/격국/최종 용신, 오행 점수/확률/인구 우열, 사건 날짜는 구현하지 않는다. 구조에 대한 제한된 프로젝트 해석을 전체 길흉 확정으로 부풀리는 것이 주요 위험이다.

## 판정과 자료

일간 기준 canonical 십성, 월지 본기, 네 기둥의 실제 지장간을 사용한다. 같은 오행의 지장간 유무를 뿌리 유무로 기술하지만 개수로 강약을 확정하지 않는다. 인성의 존재는 도움의 단서이며 뿌리와 동일하게 취급하지 않는다. 식상/인성 또는 식상/관성의 공존은 실제 제화·합충·성격/직업 적합성 판정이 아니다. 재성의 겉/안쪽 위치를 수입/사업 능력으로 바꾸지 않는다.

문헌의 범위는 [057](057-whole-chart-reading-contract.md)의 滴天髓闡微·窮通寶鑑 참고와 canonical 관계다. 겨울 금의 한랭/불 고려는 메모의 계절 단서로만 쓰며 최종 용신을 지정하지 않는다. 새 지식/판정/문구 버전은 각각 관리한다. 전문가·경험적 정확성 승인은 미완료다.

critical full-report 보류를 유지한다. 051에서 검증된 날짜 관례 쌍에 한해서만 선택 명식의 제한된 구조 풀이를 가정 표시와 함께 제공하고 대안은 자신의 일간으로 다시 계산한다. 미상/자료 누락/설명되지 않은 critical은 닫는다.
