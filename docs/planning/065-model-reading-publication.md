# 065. 실제 생성 본문의 게시 복구

## 목표와 범위

사용자가 실제 모델로 충분한 풀이를 요청한 뒤 이전에 동작한 연결로 계속 진행하도록 지시했다. 이전 성공 기록과 현재 서버는 로그인된 Codex Sol 6.1/xhigh 경로다. 상용 기본 설정은 OpenAI GPT-5.4이나 로컬 인증은 없고 Vercel 환경 목록 조회는403이었다. Codex 결과를 상용 API 검증으로 보고하지 않는다.

현재 열린 테스트 결과의 같은 입력을 사용한다. 초기 읽기에서만 서버의 natal/선택 theme/기존 plan 판단과 기간 비교를 문장화 자료로 공급한다. 생성 계약에 실제 제목과 실제 공급된 fact ID를 명시하고, 검증된 해당 계약의 본문은 고정 단문으로 교체하지 않는다. 기존 fallback과 critical 전체 보류는 유지한다. 다른 생일이나 과거 원고로 성공을 대체하지 않는다.

## 위험과 검증

새 판단 엔진을 만드는 작업이 아니다. 원국 종합 강약/용신/분야별 길흉/사건 시기는 여전히 미지원이다. 특히 금전의 위치·분류 뜻을 개인 수입이나 축적 운으로 승격하지 않는다. 길이만으로 콘텐츠를 승인하지 않으며064의4412자 기준과 독립 내용 검토를 따로 확인한다.

제목·실제 ID/허구 ID·두 언어·모델 호출 수·실패 fallback·critical0호출과 게시 본문 유지의 회귀 검사를 한다. OpenAI 요청은 mock으로 계약을 검사하고 fallback-only 사용자 시나리오를 실행한다. 사용자가 요청한 실제 결과만 기존 연결로 생성하며 테스트를 위해 유료 provider를 호출하지 않는다. 실제 응답과 표시 질문/선택 답을 동결해 reader/evidence 독립 job으로 검토한다. UI 접근 실패는HOLD로 기록한다.

## 진행

연결과 생성/게시 계약 복구는 완료했다. 같은 입력의 실제 Codex Sol6.1/xhigh 결과가 생성·검증·게시됐다. 본문 분량은 충족했지만 독립 독자 검토에서 궁금증 충족 FAIL/전체 질문 partial이므로 실질적인 풀이 완성은 Needs review다. 상용 GPT-5.4 호출은 인증 미확인으로 미실행이다.

## 적용과 회귀

promptv20은 실제 두 언어 제목·실제 fact ID allowlist·요약5문장 계약을 요청에 공급한다. OpenAI strict schema에도 같은 title/ID enum을 넣는다. 허구 ID와 다른 장의 근거는 여전히 거부한다. 초기 읽기는 natal/선택된 theme/기존 분야 규칙·현재/다음 비교를 별도 쓰기 자료로 공급하고, 실제 게시와 같은 전문 문단 제외 기준으로4412자를 검사한다. 통과 후 붙인 writing.1 표식만 publication.2가 장문으로 게시한다. legacy 모델 원고는 이 표식 없이 기존 제한을 그대로 따른다. natal copy/selection의 계약 metadata도 실제 카탈로그의2026-10-11.1과 맞췄다.

최종 관련 API101·웹helper14 PASS. 격리 fallback 실제 loopback HTTP는456 PASS/3 WARN/기존음력30일 FAIL1, 외부 생성0, helper 종료 확인이다. 첫 두 회귀의 호환 객체 optional 속성·검사 fixture·기대 prompt 버전 실패와 수정 로그를 등록 root에 보존한다. API만 기존 Codex 설정으로 재시작했고 웹과 원본 결과는 유지했다. 한 번의 사용자 요청 실제 생성이 성공했으며 회귀 검사로 모델을 호출한 것이 아니다. 브라우저 연결은 다시 시도했으나 신뢰 bridge 오류로 UI HOLD다.

## 실제 결과와 남은 문제

현재 테스트 입력1993-04-22 03:40 남성 제천을 유지했다. 새 결과 `a196da3547344cecb49e89bff1c85133`의 실제 표시 본문은 특징876/연애1117/금전685/직업1125/흐름1437, 합계5240자로 기준1103자의4.75배다. 새 writing 계약을 통과한 실제 Codex 본문이며 고정 fallback으로 대체되지 않았다. 원본 응답·스트림·검증 결과·정확한 게시 JSON 일치·no-store·문서HTTP200을 등록된 증거 root에 보존했다. 이전 결과와 개인 경계 명식의 보류는 유지했다.

독립 reader는 쉬운 문구·질문 적합·메뉴 흥미·실제 도화 답을 PASS로 읽었지만, 본문은 돈·직업의 개인별 결론 대신 구별과 한계를 반복해 궁금증 충족 FAIL/partial로 판정했다. 이는 부족한 백엔드 판단을 장문 생성만으로 해결할 수 없음을 보여준다. 원국 종합/분야별/기간 종합 판단은 여전히 미구현이며 또 다른 모델 호출이나 한계 문구의 반복으로 완료 처리하지 않는다. 실제 상용 API, 브라우저 시각 확인, 전문가·실사용자 승인은 별도 미검증이다.

최종 `report-065.json`은 code PASS/content FAIL, reader FAIL/evidence PASS, 본문 partial/선택 답 met다. 독립 두 역할의 job hash·모든 인용 계약을 검증했으며 `input_blind_only` 범위다. 근거 역할의 최초 응답에 실제 자료에 없는 인용 하나가 있어 evaluator가 거부한 원본을 별도로 보존했고, 해당 역할이 인용만 교정한 새 응답으로 재평가했다. 실패를 다른 역할의 PASS로 상쇄하지 않았다. 재구성한 쓰기 자료는 동결된 원본 사실에서 만든 검토 projection이며 최초 provider 요청 bytes를 보유했다고 주장하지 않는다.
