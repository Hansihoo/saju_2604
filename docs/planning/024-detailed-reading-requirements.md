# 024. 상세 사주풀이 결과 요구사항

## 목적

사용자에게 보여주는 사주풀이가 너무 짧거나 뭉뚱그려지지 않도록, 섹션별 필수 항목을 더 강하게 고정한다.

이번 단계의 목표는 아래와 같다.

1. 결과가 충분히 길고 구체적으로 나오게 만든다.
2. 근거를 먼저 말하고, 뒤에 쉬운 해석을 붙이는 흐름을 고정한다.
3. 연애운 안에 결혼운을 별도 하위 섹션으로 넣는다.
4. 재물운에는 상대적 평가와 좋아질 가능성이 큰 시기를 반드시 넣는다.
5. 내용이 지나치게 짧으면 실패로 보고 fallback 또는 재시도를 탄다.

---

## 전체 결과 구조

큰 주제는 아래 5개를 유지한다.

1. 내 사주의 특징
2. 연애운
3. 재물운
4. 직장운
5. 대운 흐름

---

## 공통 작성 원칙

모든 큰 섹션은 아래 순서를 기본으로 가진다.

1. 작은 제목
2. 근거
3. 쉬운 해석
4. 장점
5. 단점 / 주의점
6. 어떻게 해야 하는지

작성 원칙:

- 근거는 전문가처럼 계산된 사실을 먼저 설명한다.
- 쉬운 해석은 사주를 모르는 사람도 이해할 수 있게 풀어쓴다.
- 좋은 말만 하지 않는다.
- 단점과 관리 포인트를 반드시 적는다.
- 적은 데이터는 없는 데이터와 같다고 보고, 지나치게 짧은 문장은 실패로 본다.
- 이모티콘은 사용하지 않는다.

---

## 1. 내 사주의 특징

필수 항목:

- 작은 제목
- 근거
- 쉬운 해석
- 평균적인 사주와 비교했을 때 다른 점
- 장점
- 단점 / 주의점
- 어떻게 해야 하는지
- 마지막 결론

중요 포인트:

- 다른 사람들과 무엇이 다른지 반드시 들어가야 한다.
- 장점과 단점을 같이 보여줘야 한다.
- 단순히 좋다 / 나쁘다가 아니라 구조적 특징을 설명해야 한다.

---

## 2. 연애운

필수 항목:

- 작은 제목
- 근거
- 쉬운 해석
- 장점
- 단점 / 주의점
- 어떻게 해야 하는지

추가로 반드시 포함할 하위 섹션:

### 결혼운

필수 항목:

- 작은 제목
- 결혼운의 특징
- 잘 맞는 배우자
- 잘 맞지 않는 사람
- 결혼운 관리 조언

중요 포인트:

- 예시처럼 `늦을수록 안정감이 커지는 결혼운` 같은 작은 제목 형태가 좋다.
- 연애와 결혼을 같은 이야기로 섞지 않고, 결혼운을 별도로 보여준다.

---

## 3. 재물운

필수 항목:

- 작은 제목
- 근거
- 쉬운 해석
- 장점
- 단점 / 주의점
- 어떻게 해야 하는지

추가 필수 항목:

- 상대적으로 좋은지 / 나쁜지 / 보수적인지 / 기복이 큰지
- 언제 좋아질 가능성이 큰지
- 돈 문제에서 특히 조심해야 할 것

중요 포인트:

- 재물운은 “돈을 잘 버는가”만이 아니라 “돈을 어떻게 다뤄야 하는가”까지 설명해야 한다.
- 현재와 다음 대운 흐름을 이용할 수 있으면 시기 설명을 반드시 붙인다.

---

## 4. 직장운

필수 항목:

- 작은 제목
- 근거
- 쉬운 해석
- 장점
- 단점 / 주의점
- 잘 맞는 일 방식 / 조직 환경
- 어떻게 해야 하는지

중요 포인트:

- 직업 적성보다도, 어떤 환경에서 강점이 살아나는지를 꼭 설명한다.
- 사람 문제보다 구조 문제가 더 중요한 경우도 분리해서 설명할 수 있어야 한다.

---

## 5. 대운 흐름

필수 항목:

- 현재 흐름
- 다음 흐름

각 흐름마다 아래를 넣는다.

- 작은 제목
- 근거
- 쉬운 해석
- 좋은 점
- 나쁜 점 / 주의점
- 어떻게 해야 하는지

중요 포인트:

- 여러 대운을 다 길게 풀지 않는다.
- 사용자 화면에는 현재와 다음 흐름만 노출한다.
- “이 시기에는 무엇이 좋아질 수 있는지 / 무엇을 조심해야 하는지 / 어떤 태도가 맞는지”를 중심으로 쓴다.

---

## 시스템 규칙

LLM 출력은 아래 기준을 만족해야 한다.

- 필수 섹션 누락 금지
- 필수 하위 항목 누락 금지
- 근거 없는 주장 금지
- 지나치게 짧은 문장 금지
- 상위 n% 같은 표현은 기준선이 들어오기 전까지 금지
- 이모티콘 금지
