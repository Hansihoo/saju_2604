# suju-insight MVP Outline

## 목표

- 사주 웹 서비스의 첫 실행 가능한 프로젝트 구조를 만든다.
- 랜딩 화면에서 서비스 톤과 방향을 먼저 보여준다.
- 백엔드에서는 추후 해석 엔진을 연결할 수 있도록 API 뼈대를 마련한다.

## 이번 단계에서 포함한 것

- React + Vite 기반 웹 앱 초기화
- FastAPI 기반 API 초기화
- 로컬 개발 기준 프록시 및 CORS 설정
- MVP 방향이 드러나는 첫 화면 구성

## 이번 단계에서 아직 제외한 것

- 실제 사주 계산/해석 로직
- 사용자 인증
- 데이터베이스 연결
- 결제 및 관리자 화면

## 바로 다음 작업

1. 사주 입력에 필요한 필드 목록 확정
2. 결과 화면 정보 구조 정의
3. PostgreSQL 스키마 초안 설계
4. API 입력/응답 모델과 에러 규칙 정리
