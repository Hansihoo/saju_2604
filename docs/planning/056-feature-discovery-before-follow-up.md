## 범위와 구현

최신 사용자 보정은 아래 최초 구현과 단독 소제목 이력을 대체한다. 존재만 선언하는 소제목을 제거하고 기존 특징 설명 안에 태극의 뜻을 연결한다. 추가 질문은 ‘내 사주에 있는 태극귀인은 내 삶에 어떤 영향을 미칠까?’로 작성한다. 실제 존재를 먼저 설명하는 원칙, 유효fact/질문 조건과 판단 범위는 유지한다.

기존055의 제한된 전통 보조 주제와 사실/판정 경계를 유지하는 콘텐츠 연결 변경이다. 계산033, 날짜 경계 보류, 전체 길흉·강도·사건 시기 허용 범위는 바꾸지 않는다. 새 상호 강화/취소나 구원자·성공 보장을 만들지 않는 것이 주요 검증 위험이다.

- 본문은 **실제 발견 → 쉬운 뜻 → 이미 읽은 복/부담과의 구별 → 추가 질문** 순서로 연결한다. 선택된 유명 특징의 이름은 본문에서 소개하고, 관법·한자·계산 위치·원문·대안은 기본 접힘 메모에 둔다.
- 태극 소개 문단은 카탈로그의 선택적 `introductions`로 관리한다. 해당 질문의 조건과 실제 `eligible_matches`가 모두 확인될 때 backend에서만 삽입한다. 특정 생일이나 frontend 분기로 붙이지 않는다.
- 배움·글의 복과 태극의 시작/마무리 뜻을 구별한다. 함께 있다고 복의 크기를 더하거나 고독이 없어졌다고 말하지 않는다. 원문의 始終相保 범위를 넘는 회복·취업·도움의 날짜는 추가하지 않는다.
- 도화도 본문에서 존재를 먼저 알려 질문과 연결한다. 없는 특징과 잘못된 관법은 소개하지 않는다.
- knowledge `.1`은 유지하고 distinctive rules `.2`/copy `.3`, question copy `.5`, category copy `.10`을 독립 관리한다. 새 응답 schema나 frontend 계산은 없다.
