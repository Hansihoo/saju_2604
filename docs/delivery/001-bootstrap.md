# Bootstrap Delivery Note

## 완료 내용

- `apps/web`와 `apps/api`를 포함한 기본 모노레포 구조를 생성했다.
- 웹 첫 화면에서 서비스 방향, MVP 범위, 입력 미리보기를 확인할 수 있게 했다.
- API 헬스체크 엔드포인트를 추가해 웹과 연결 가능한 최소 백엔드 기반을 만들었다.

## 확인 필요

- 실제 서비스명 `suju-insight`를 그대로 사용할지
- 비회원 조회와 회원 저장 기능 중 어느 쪽을 먼저 열지
- 출생 시간 미입력 허용 여부
- 사주 결과 저장을 첫 MVP에 포함할지
