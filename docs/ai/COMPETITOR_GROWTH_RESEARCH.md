# Consumer fortune service growth research

조사일: 2026-10-05. 범위: 점신, 포스텔러, 헬로우봇의 공개 서비스 설명·운영사 자료·대표 인터뷰. 제품 코드와 계산·해석 규칙은 변경하지 않았다.

후속 제품 결정: 사용자는 서비스 수익화를 현재 목표에서 제외하고 흥미·공유·재방문에 집중하기로 했다. 아래 유료 서비스 정보는 경쟁사 조사 기록이며 우리 구현 권고가 아니다. 실제 보강 순서는 [흥미 중심 UX 계획](../planning/038-interest-led-reading-experience.md)을 따른다.

후속 사용자 보정: 성격·연애 타입을 알아보는 진입 질문은 거부됐다. 앞으로의 인연·취업·직장 변화와 시기가 주력 관심사다. 기존 성향 규칙에 맞춘 제목 후보를 폐기하고, 원하는 답에 필요한 기간 사실과 검토된 규칙을 먼저 갖추는 순서로 계획을 수정했다.

## 조사 기준

- 이용 규모, 실제 제공 기능, 운영자의 설명, 우리 제품에 대한 제안을 구별한다. 공개 기능과 인터뷰만으로 개별 기능의 성장 기여도를 증명할 수는 없다.
- 누적 다운로드·가입자·메신저 유입·평가 수는 서로 다른 지표다. 이를 현재 활성 이용자나 서비스 간 순위로 비교하지 않는다.
- 운영사의 정확도·국내 1위·예측 표현은 마케팅 주장이다. 인기도를 사주 해석이나 사건 예측의 검증 결과로 사용하지 않는다.
- 웹 공개 자료를 읽었다. 경쟁 앱의 입력·결제·공유를 직접 실행하거나 유료 결과를 구매하지 않았다.

## 제품 관점의 해석

아래는 관찰에서 도출한 가설이다. 경쟁사의 내부 실험이나 전환율 자료를 확보한 결론이 아니다.

| 장치 | 사용자가 얻는 경험 | 예상되는 역할 | 우리 제품의 적용 판단 |
| --- | --- | --- | --- |
| 구체적인 고민을 제목으로 제시 | 지금 궁금한 내용을 골라 읽는다. | 첫 선택과 결과 열람을 유도할 수 있다. | 우선 적용 검토. 질문과 실제 답변 범위를 먼저 맞춘다. |
| 캐릭터별 일관된 대화 | 누가 어떤 방식으로 읽어주는지 기억한다. | 친밀감과 브랜드 기억에 도움이 될 수 있다. | 기존 도깨비의 반말·표정·반응을 일관되게 편집한다. 시비·모욕은 제외한다. |
| 새로운 주제와 계절에 맞는 콘텐츠 | 자신의 상황이 달라질 때 다시 찾는다. | 재방문 이유를 만들 수 있다. | 문장만 바꿔 동일 판정을 반복하지 않는다. 새로운 질문에 필요한 사실과 규칙이 있어야 한다. |
| 오늘의 짧은 결과 | 아침이나 중요한 일을 앞두고 확인한다. | 사용 습관을 만들 수 있다. | 기존 날짜·기간 계산 범위에서 오늘의 핵심과 행동을 제공한다. 날짜가 달라져도 같은 해석일 수 있으며 표현만 바꿔 새로운 예측처럼 만들지 않는다. |
| 메신저·제휴 서비스에서 접근 | 평소 쓰는 곳에서 쉽게 시작한다. | 신규 유입의 마찰을 줄일 수 있다. | 현재 모바일 웹과 공유 링크를 먼저 검증한다. 플랫폼 입점은 별도 검토한다. |
| 무료 결과에서 상세 콘텐츠·상담으로 연결 | 가볍게 읽고 더 궁금한 내용으로 이동한다. | 깊은 이용과 매출을 연결할 수 있다. | 현재는 결과 만족과 질문별 정보 차이를 먼저 검증한다. 새 유료 기능을 이 조사만으로 구현하지 않는다. |

공유 카드가 신규 사용자를 얼마나 만들었는지에 관한 비교 가능한 공개 지표는 확보하지 못했다. 우리 서비스의 결과 공유는 사용자가 이미 요청한 핵심 기능이며, 그 효과는 직접 측정해야 한다.

## 현재 제품에 권하는 순서

1. **원하는 답부터 정의한다.** 인연과 취업 시기를 첫 목표로 잡고 필요한 기간 사실·조건·해석 규칙을 검토한다. 현재 성향 풀이가 가능한 질문으로 사용자 의도를 대체하지 않는다. 제목이 약속한 정보가 실제 결과에 있는지 확인하고 준비된 질문만 공개한다.
2. **한 질문에 대한 만족을 확인한다.** 결과는 질문 → 직접 답변 → 예시 장면 → 장점과 부담 → 행동 → 작은 분석 노트 순서를 유지한다. 첫 답변이 나머지 문단의 의미를 잡아줘야 한다. 본문과 분석 노트는 사용자 요청대로 항상 표시한다.
3. **도깨비의 반응을 편집한다.** 표정은 결론을 읽는 순간과 연결한다. 말투의 재미는 현실적인 상황과 비유에서 만들고, 근거 없는 자신감이나 상대를 비난하는 대사는 쓰지 않는다.
4. **공유할 내용을 사용자가 고르게 한다.** 선택한 질문과 같은 규칙의 답변, 캐릭터 표정을 카드에 담는다. 출생정보를 넣지 않으며 맥락과 제한을 지워 단정적인 예언으로 만들지 않는다. 공유 링크에서 다시 자기 질문을 고를 수 있는 흐름은 후속 구현 제안이다.
5. **재방문 이유를 검증한다.** 오늘의 결과는 짧게 확인할 수 있게 하고, 다음 질문은 지원되는 범위에서 추천한다. 새로운 콘텐츠 수보다 질문별 정보 차이와 읽은 뒤 남는 의미를 우선한다.

초안의 관계 성향·책임 성향·편한 상대 유형 제목 후보는 사용자 피드백으로 폐기했다. 첫 개발 목표는 “인연은 언제쯤 들어올까?”, “취업운은 언제쯤 풀릴까?”다. 시기 질문은 필요한 사실·규칙과 한계를 검토한 뒤 공개하며, 아직 지원한 기능으로 기록하지 않는다.

연인을 만나는 날짜, 취업·승진 시점, 다른 사람 대비 운의 순위는 관심을 끌 수 있는 질문이다. 현재 프로젝트는 이를 답할 검토된 규칙·관측 자료·비교 모집단이 부족하다. 경쟁사의 강한 예측 제목을 현재 계산값에 임의로 붙이지 않는다. 상세 경계는 [SAJU_READING_AGENT.md](SAJU_READING_AGENT.md), [질문·지식 계약 계획](../planning/036-knowledge-backed-question-readings.md)을 따른다.

## 콘텐츠 관리와 검증에 연결

- 질문마다 필요한 계산 사실, 적용 규칙, 제외 조건, 답변 범위, 문구 버전과 공유 문장을 연결한다. 기존 지식/규칙/문구 버전을 분리해 유지한다.
- 문구·표정 변경과 해석 규칙 변경을 별도 실험으로 관리한다. 캐릭터나 자극적인 제목이 같은 규칙의 의미를 바꾸지 않게 한다.
- 기존 독립 역할 검증기에 넣을 후보 평가지표: 선택 질문에 답했는지, 다른 주제와 정보가 겹치는지, 기억할 문장이 있는지, 예시를 실제 사실로 읽게 하지 않는지, 분석 노트와 본문이 같은 근거를 쓰는지, 공유 때 의미가 유지되는지.
- 실제 사용자 검증은 별도로 필요하다. 질문별 선택 → 입력 완료 → 결과 열람 → 공유 실행 → 공유를 통한 신규 시작을 비교한다. 화면에 보이는 반응 버튼이나 체류 시간 하나만으로 만족도·예측 적중을 확정하지 않는다.
- 소규모 사용자 인터뷰에서 “무슨 답을 얻었는지”, “친구에게 보내고 싶은 문장은 무엇인지”, “부족하거나 반복됐다고 느낀 내용은 무엇인지”를 확인한다. 합성 에이전트 평가는 실제 사용자 흥미를 대체하지 않는다.

## 완료와 남은 범위

공개 출처 확인, 지표 의미·날짜 구분, 성장 장치의 가설 정리, 현재 지원 범위를 반영한 우선순위 제안을 완료했다. 실제 사용자 전환·재방문·공유 효과, 경쟁사 내부 성과, 전문가 해석 검토는 확인하지 않았다. 이번 작업은 조사와 문서화이며 제품 코드·프롬프트·카탈로그·계산 정책 변경은 없다.
