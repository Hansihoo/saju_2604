# DEVELOPMENT_CHECKLIST

## 목적
개발 회차를 시작하기 전에 방향을 잃지 않도록 확인하는 체크리스트다.

## 개발 시작 전
- [ ] 참조할 기능 명세가 있다.
- [ ] 개발 전달 문서가 있다.
- [ ] 이번 회차 목표가 한 문장으로 설명된다.
- [ ] 이번 회차 비범위가 적혀 있다.
- [ ] 필요한 환경값 중 미정 항목이 없다.

## 구현 중
- [ ] 이번 회차 범위를 넘지 않았다.
- [ ] 변경 파일/영역을 알고 있다.
- [ ] 로그를 어디서 볼지 알고 있다.

## 구현 후
- [ ] 관련 build 실행
- [ ] 관련 test 실행
- [ ] 관련 lint/typecheck 실행
- [ ] 로그 또는 실제 동작 확인
- [ ] 실패한 것이 있으면 이유 기록

## 문서화
- [ ] 이번 회차에서 결정된 것 기록
- [ ] 보류된 것 기록
- [ ] 다음 회차 시작점 기록

## 완료 판단
- [ ] 기획 의도와 구현 방향이 어긋나지 않는다.
- [ ] acceptance criteria와 연결해 설명할 수 있다.
- [ ] 다음 회차를 바로 시작할 수 있다.
