# IMPLEMENTATION_HANDOFF_TEMPLATE

## 목적
기능 명세를 개발 회차에서 바로 사용할 수 있는 전달 문서로 바꾸기 위한 템플릿이다.

## 언제 쓰는가
- 구현 시작 직전
- 여러 회차로 나눠 개발할 때
- 이번 회차 범위를 정확히 자르고 싶을 때

## 문서에 반드시 들어갈 것
1. 참조 기능 명세
2. 이번 회차 목표
3. 이번 회차 범위
4. 건드릴 영역
5. 검증 방법
6. 로그 확인 포인트
7. 보류 항목
8. 다음 회차 시작점
